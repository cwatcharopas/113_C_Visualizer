      วิธีใช้
      
  
      เลือกตัวอย่าง หรือพิมพ์โปรแกรม C สั้น ๆ ที่มี main แล้วกด ▶ เริ่มจำลอง จากนั้นเดินหน้า/ถอยหลังทีละขั้นเพื่อดู stack frame ถูก push (เมื่อเรียกฟังก์ชัน) และ pop (เมื่อ return)
      
  
      
    
      Ctrl+Enterเริ่มจำลอง

      สิ่งที่รองรับ (v1)
      
  
      int long float double char · #define ชื่อ ค่า · ตัวดำเนินการ comma (,) · ตัวแปร extern · ฟังก์ชัน prototype และ recursion · if/else while for do-while break continue · ตัวแปร global และ static · printf (%d %i %ld %c %f %lf %e %g %x %s) · puts("...") putchar(c) · sqrt (<math.h>) · rand srand (ลำดับเดียวกับ glibc บน Linux) · scanf (%d %i %ld %f %lf %c กับ &ตัวแปร) และ getchar() กับค่าคงที่ EOF โดยอ่านจากช่อง stdin ซึ่งแก้ได้ทุกเมื่อ (เครื่องมือจะจำลองใหม่และอยู่ที่ขั้นเดิม)
      
  
      ยังไม่รองรับ: array, pointer, struct, switch, unsigned short, แมโครที่มีพารามิเตอร์ — ถ้าใช้จะขึ้นข้อความบอกบรรทัดและสิ่งที่ยังไม่รองรับ
      
  
      long มีขนาด 8 ไบต์ (64 บิต) ตาม gcc บน Linux 64 บิตที่ใช้ในห้องปฏิบัติการ ถ้าค่าเกินช่วงนี้เครื่องมือจะหยุดและแจ้ง (บาง compiler บน Windows เช่น MINGW64/UCRT64 ใน MSYS2 ใช้ long 4 ไบต์) · ถ้าข้อมูลเข้าหมด scanf และ getchar คืนค่า EOF (-1) แทนการรอ · getchar อ่านตัวอักษร ASCII เท่านั้น
      
  
      สีและเครื่องหมายบรรทัด
      
  
      ▷ เหลือง กำลังจะทำ: บรรทัดที่จะเรียกฟังก์ชัน (ยังไม่ได้เข้าไป) หรือหัวฟังก์ชันตอนเพิ่งเข้ามา (ยังไม่ได้ทำบรรทัดใดในฟังก์ชัน) · ⌨ เหลืองเข้ม ฟังก์ชันอ่านข้อมูล (scanf, getchar) กำลังอ่านจาก buffer ของ stdin ดูตัวอักษรที่ถูกไฮไลต์ใต้ช่อง stdin · ✔ เขียว บรรทัดที่เพิ่งทำเสร็จ · ↳ ฟ้า บรรทัดที่ผู้เรียกรอผลอยู่ · ⚠ บรรทัดที่เกิดข้อผิดพลาด
      
  
      ส่วนต่าง ๆ
      
  
        
    
      • Standard Library: การเรียก printf scanf getchar sqrt ฯลฯ แสดงเป็น frame เส้นประ เห็นค่าที่ส่งเข้าไปและค่าที่ส่งกลับ แต่ไม่แสดงการทำงานภายใน ฟังก์ชันแสดงผลใช้ 2 ขั้น (▷ เรียก แล้ว ✔ พิมพ์และ pop) ฟังก์ชันอ่านข้อมูลใช้ 3 ขั้น (▷ เรียก, ⌨ อ่านจาก buffer, ✔ pop) ปิดสวิตช์ "แสดงขั้นของ Standard Library" เพื่อให้แต่ละบรรทัดเหลือขั้นเดียว
        • 
    
      • การคำนวณในขั้นนี้: นิพจน์ถูกคำนวณทีละตัวดำเนินการ เช่น การหารจำนวนเต็ม การแปลงชนิด short-circuit และค่าที่ฟังก์ชันส่งกลับ
        • 
    
      • หน้าจอ terminal: แสดงสิ่งที่โปรแกรมพิมพ์ (stdout) และข้อความที่ผู้ใช้พิมพ์เข้าทาง stdin แบบขีดเส้นใต้ บรรทัดที่ขีดเส้นใต้ปรากฏเพราะ terminal แสดงสิ่งที่เราพิมพ์ให้เห็น (echo) ไม่ใช่เพราะโปรแกรมพิมพ์ออกมา ปิดสวิตช์ "แสดงข้อความที่พิมพ์เข้า" เพื่อดูเฉพาะ stdout ของโปรแกรม เหมือนรันด้วย ./a.out < input.txt
        • 
    
      • ตารางติดตามค่า: รวมทุกขั้นที่ค่าตัวแปรเปลี่ยน (เดิม → ใหม่) มีการตัดสินใจของ if/loop หรือมีการพิมพ์ เหมือนตาราง trace ที่เขียนเอง คลิกแถวเพื่อกระโดดไปขั้นนั้น
        • 
  
      
  
      ข้อตกลงของเครื่องมือนี้
      
  
        
    
      • ที่ในหน่วยความจำกับ scope เป็นคนละเรื่องกัน เมื่อเข้าฟังก์ชันหรือบล็อก ตัวแปร local ทุกตัวของบล็อกนั้นถูกจองที่ใน stack frame ทันที (ตามมาตรฐาน C) แต่ชื่อของตัวแปรอยู่ใน scope ตั้งแต่บรรทัดที่ประกาศเป็นต้นไป ก่อนถึงบรรทัดนั้น โค้ดยังเรียกใช้ชื่อนี้ไม่ได้ แถวของตัวแปรจึงจางและมีป้าย "ยังไม่อยู่ใน scope · scope เริ่มบรรทัด N"
        • 
    
      • ตัวแปร local ที่ยังไม่กำหนดค่าแสดงเป็น ? และถ้าโปรแกรมอ่านค่านั้น เครื่องมือจะหยุดและอธิบาย (ในโปรแกรมจริงจะได้ค่าขยะ)
        • 
    
      • argument ถูกคำนวณจากซ้ายไปขวา (มาตรฐาน C ไม่ได้กำหนดลำดับ gcc บน x86-64 มักทำขวาไปซ้าย) ถ้าลำดับมีผลต่อผลลัพธ์ เครื่องมือจะแจ้งหมายเหตุ
        • 
    
      • undefined behavior เช่น integer overflow, หารด้วยศูนย์, i = i++ จะถูกหยุดพร้อมคำอธิบาย ไม่จำลองต่อแบบเดา ๆ
        • 
    
      • ที่อยู่หน่วยความจำ (ถ้าเปิดแสดง) เป็นค่าจำลอง ไม่ใช่ที่อยู่จริง
        • 
    
      • จำกัด 10,000 ขั้น เพื่อกัน loop ไม่รู้จบ
