C ที่รองรับ
      
    
        
  • struct ของโหนด 1 แบบ: ข้อมูล int หรือ char 1 ฟิลด์ และ pointer ไปยัง struct เดียวกัน 1 ฟิลด์ (next) หรือ 2 ฟิลด์ (next, prev) ตั้งชื่อฟิลด์ได้เอง ใช้ typedef ได้
    • 
        
  • ชนิด int, char, pointer ไปยังโหนด, **, อาเรย์ของ int/char ที่มีค่าเริ่มต้น
    • 
        
  • if/else, while, do-while, for, break, continue, ฟังก์ชันและ recursion
    • 
        
  • malloc(sizeof(struct node)), free, printf (%d %c), exit, getchar, putchar, scanf (%d %c กับ &ตัวแปร), cast (int) (char)
    • 
        
  • ยังไม่รองรับ: ตัวแปร global, #define, switch, %s %p, ตัวดำเนินการ . และ comma, ++i ในนิพจน์, float/double

ตัวแปร (แยกตามฟังก์ชัน) กรอบส้ม = ฟังก์ชันที่กำลังทำงาน · กลุ่มของฟังก์ชันหายไปเมื่อฟังก์ชันนั้นจบ

    

    
หมายเหตุสัญลักษณ์ในแผนภาพ: ลูกศรเส้นทึบ = next · ลูกศรเส้นประ = prev · ป้ายพื้นเข้ม = ตัวแปรใน main · ป้ายกรอบส้ม = ตัวแปรของฟังก์ชันที่กำลังทำงาน · ป้ายกรอบประ = ตัวแปรของฟังก์ชันที่รออยู่ · เส้นหนาสีส้ม = เพิ่งเปลี่ยนในขั้นนี้ · กรอบประสีแดง = free แล้ว · พื้นเทา = leak

  โปรแกรมที่อ่านข้อมูลเข้า (getchar, scanf) อ่านจากช่อง stdin ใต้โค้ด ถ้าข้อมูลหมดจะได้ EOF (-1) ทันที ไม่หยุดรอแบบโปรแกรมจริง.
  ในช่องหน้าจอ terminal ข้อความขีดเส้นใต้คือสิ่งที่ผู้ใช้พิมพ์เข้า ซึ่ง terminal แสดงให้เห็นเอง (echo) โปรแกรมไม่ได้พิมพ์ข้อความนี้ ปิดสวิตช์ "แสดงข้อความที่พิมพ์เข้า" เพื่อดูเฉพาะ stdout ของโปรแกรม.
  ตำแหน่ง (position) เริ่มนับที่ 0 · ค่า data เป็น int ระหว่าง −999 ถึง 999 · แสดงได้ไม่เกิน 12 โหนด.
  เครื่องมือนี้รันโค้ด C อ้างอิงด้วยตัวแปลภาษาในเบราว์เซอร์ (ไม่มีการส่งข้อมูลออกนอกเครื่อง) ลำดับบรรทัดที่ทำงานตรวจเทียบกับ gcc แล้ว.
  พฤติกรรมที่ไม่นิยาม (undefined behavior) เช่น ใช้หน่วยความจำหลัง free จะหยุดพร้อมข้อความเสมอ ส่วนโปรแกรมจริงอาจดูเหมือนทำงานได้.
